## 一键启动脚本（start.bat / start.command / start.sh）

新增三个根目录脚本，零改 `src/`、`tests/`、`scripts` 字段。

- `start.bat`（65 行，UTF-8 无 BOM，CRLF）：chcp 65001 → 检查 node → 检查 node_modules → `call npm install` → `call npm run dev -- --open`。
- `start.command` / `start.sh`（各 56 行，UTF-8 无 BOM，LF，内容逐字节相同）：同逻辑的 bash 版。
- `package.json`：`files` 追加三项。`README.md` 第 1 节加「最快方式：双击启动」，`QUICKSTART.md` 顶部加双击提示。

### 两个真实踩到的坑（重要，以后再写 bat 要记住）

1. **`rem` 注释里不能有中文**。UTF-8 + `chcp 65001` 下 cmd 解析批处理会出现偏移错位，
   中文注释行被当成命令执行：报 `'，package.json' is not recognized ...`。
   → 所有 `rem` 行改纯 ASCII；中文只放在 `echo` 里（echo 正常）。
2. **`exit /b 1` 放在 `if ... ( ) else ( )` 的嵌套块里会丢掉退出码**（实测返回 0）。
   同结构在单级块里正常。
   → 改用 `goto :label` 把错误分支移到文件末尾，退出码恢复为 1。

### 已知限制（已写进报告）

- Mac/Linux 需用户自己 `chmod +x`（Windows 上无法设置可执行位）。
- Windows SmartScreen 首次可能提示未知发布者。
- Ctrl+C 时 cmd 会问 "Terminate batch job (Y/N)?"，答 N 才会回到脚本打印"服务器已停止"。
