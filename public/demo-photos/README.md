# 演示照片

把 3 张你自己拍的照片放在这个目录，演示时在「生成信物」里直接选取即可。建议：

| 文件名 | 内容 | 用来说明 |
|---|---|---|
| `nature.jpg` | 山、湖、森林一类 | 自然风光 |
| `heritage.jpg` | 古迹、石窟、老建筑 | 人文历史 |
| `watertown.jpg` | 水乡、古镇 | 水乡古镇 |

**为什么仓库里没有预置图片**：这是隐私项目，演示素材用真实拍摄的照片更有说服力；
同时避免把第三方图片的版权和拍摄地信息带进仓库。

建议先在本地把照片长边压到 2000px 以内再放进来——应用自己还会再压到 720px，
但演示时列表加载会更快。

没有照片也能跑通全流程：随便拖一张任意图片进「生成信物」即可。
